# Commands Usage

{% hint style="warning" %}
**For new staff members**, please read this page and others carefully as you will be quizzed on them.
{% endhint %}

***

## Command Letter Requirements

When executing a command on a player, this could be, for example Bring/kill/kick/etc, we strictly require our staff members to follow the rules provided in the boxes below.

{% hint style="danger" %}
X+ Letters means you must use at least how many letters of the player's username while running commands, failure to follow may result in punishment.
{% endhint %}

| 3+ Letters | 4+ Letters | Half username | Full username |
| ---------- | ---------- | ------------- | ------------- |
| :to        | :bring     | :kick         | :ban          |
| :view      | :kill      |               | :mod          |
|            | :down      |               | :unmod        |
|            | :tp        |               | :admin        |
|            | :refresh   |               | :unadmin      |
|            | :bring     |               | :helper       |
|            | :heal      |               | :unhelper     |
|            | :wanted    |               |               |
|            | :unwanted  |               |               |
|            | :jail      |               |               |
|            | :respawn   |               |               |
|            | :load      |               |               |

This is done to prevent you from running commands on people you didn't want to, and to avoid Soft-Raids (people with usernames starting with all/others).\
\
Even if each command is explained in the table above, so there is no excuse that you can use saying the command wasn't listed, the rule is simple to keep in mind: The commands that don't affect the targeted player require 3 or more letters; Other commands that affect the targeted player require 4 or more letters.

***

```
[command] [player's username]
```

For example:

```
:jail Ryan
```

***

Some commands (the last column of the table above) also work with Roblox IDs, we strongly advise you to use the player's ID, because it's unique, and there is no possibility of running the command on the wrong player.

{% hint style="info" %}
You can get a player's Roblox ID in plenty of ways, see [this guide](../technical-guides/how-to-get-a-players-roblox-id.md).
{% endhint %}

## Peacetimer Policy

In light of recent regulations announced within "staff-shouts", all staff-members are required to abide by the Peacetimer Policy.&#x20;

* In an effort to enhance the roleplay experience, the Senior High Rank Team has introduced a strict usage on how the peacetimer is utilized. Please read below for more information.
* You may put the peacetimer for these reasons:&#x20;
  * Mass RDM
  * President dying
  * Event (SHR+)
* The maximum peacetimer length that you may put is **500 seconds**. You are not permitted to put a peacetimer for longer than that, otherwise you may receive a staff-punishment. Remain cautious!
* If there are side-based roleplays occuring, please use priority timer instead as a substitute. Load/Jail any civilians who continue to shoot. Non-combative players or players without weapons are exempt from this, and may continue their roleplays as needed!

## All/Others Commands

{% hint style="success" %}
The only occasion in which you are allowed to run a command on "all" or "others" players are:

* When 5 or more players get RDMed (Mass RDMing occurring), you may run ":heal all"
* When HR+ authorize you to. You can only run the command that they authorised you to run, X time(s) they authorised you to. Not following HR instructions may result in harsh punishment.
{% endhint %}

{% hint style="danger" %}
**Never** run commands targeting "all" or "others" players, unless in (above) specified occasions. Running these commands (in any other occasion) is considered raiding and will lead you to being **blacklisted**!\
\
_&#x48;R+ members may run these commands at their own discretion, remembering that these particular cases are highly monitored and they WILL be punished if the command is run without a proper reason._
{% endhint %}

## M/H Commands

#### H Command

{% hint style="success" %}
Everyone of every rank can use the H command while on-duty. (Only in cases not described in the hint below)
{% endhint %}

{% hint style="danger" %}
You should not use the H command:

* To mess around with it;
* To send unprofessional messages;
* To send unimportant messages;
* To send user-case messages;
{% endhint %}

#### M Command

{% hint style="success" %}
You may use the M command:

* If any HR+ member allows you to; You can only run the command X time(s) they authorised you to. Not following HR instructions may result in harsh punishment.
* When the Staff Guide instruct you to do so. For example: The first elections' announcement.
{% endhint %}

{% hint style="danger" %}
**Never** run H and/or M commands, unless in (above) specified occasions. Running these commands (in any other occasion) will lead you to being **punished**!\
\
_&#x48;R+ members may run these commands at their own discretion._
{% endhint %}

***

## Off-Duty Commands Usage

{% hint style="success" %}
You may use commands off-duty if:

* You are using the private message command to send a **staff-related inquiry to other staff members**.
* You are using the private message command as a Middle Ranking+ Staff Member (IA+)
* You are an HR staff member and there is a special condition that allows you to
* You have been authorized by an SHR+ staff member. You can only run the command X time(s) they authorized you to. Not following SHR instructions may result in harsh punishment.
{% endhint %}

{% hint style="danger" %}
**Never** run commands while being off-duty, unless in (above) specified occasions. Running these commands (in any other occasion) will lead you to being **punished**!\
\
&#x53;_&#x48;R+ members may run these commands at their own discretion._
{% endhint %}

Please remember that you must attempt to hide that you are staff once off duty as well, to ensure the roleplay can be as realistic as it can be. Do not brag that you are staff or such.
