# How to get a player's Roblox ID

There are plenty of ways to get a player's Roblox ID. We will uncover them in this small guide.

***

## 1. Using their profile's link

If you have the player's Roblox Account profile link, that should look something like this&#x20;

```
https://www.roblox.com/it/users/2269104615/profile
```

```
https://www.roblox.com/users/2269104615/profile
```

```
https://www.roblox.com/it/users/2269104615/
```

```
https://www.roblox.com/users/2269104615
```

you can directly get the user's ID. It's pretty easy, and you probably already see where it is, but in order to explain better, let's introduce you to the Developer's world! \
\
See, a link is formed by various parts, divided by slashes (/), in this case, this Roblox link is formed in this way:

```
[protocol]://[website]/[country tag]/users/[user's ID]/profile
```

As you can see from the examples above, you may see a different protocol (https or http), you may see a different website (if Roblox some day decides to change their website) or you may even NOT see your country's tag or the "/profile" property.\
\
The important thing is that once you send this link into your browser, it should lead you to the user's profile page on Roblox official website.&#x20;

{% hint style="warning" %}
If you are unsure, always send the link in your browser and check if the displayed username is correct.
{% endhint %}

If you still didn't see it, the part that you want to copy is the \[user's ID] part of the link.

### How do I get a player's profile link?

If you already know their Roblox's username:

* Search their name in Roblox's search bar, in the "People" section, you will find the link in your browser's search bar.
* In some cases, click on their profile (name) to open their profile page, the link will always be in your browser's search bar.

***

## 2. Using their Username

You have 2 ways of using a player's username to search for their ID:

*   Use the "/getinfo" command from Bloxlink, with the "roblox\_user" property and insert the player's username.\
    Information on the account are displayed in the current way:<br>

## 3. Using their Discord Account

Use the "/getinfo" command from Boxlink with the "discord\_user" property, in our Discord server. It will display you which Roblox account that Discord account has linked.&#x20;

{% hint style="danger" %}
Attention! This may not correspond to the Roblox's account you're searching for, because this Roblox account is personally chosen by the Discord member!
{% endhint %}
