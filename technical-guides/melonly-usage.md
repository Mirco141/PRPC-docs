#### Tips you should consider:

* Only <mark style="color:yellow;">HR+</mark> can execute bans. In the events you see a ban worthy action, instead of waiting for a HR to ban them, kick the player and log a <mark style="color:yellow;">“Ban Bolo“</mark> on them using Melonly.

{% hint style="warning" %}
When logging a punishment like LTAP, please make sure to also include what they did before they LTAPed, in the punishment's reason.
{% endhint %}

* When logging a warning, kick or a ban bolo, please take a second to see if you’ve typed the correct name in.
* Please note, you <mark style="color:yellow;">must</mark> use decent SPaG in punishment logs as community members can see them! Not doing so will result in staff infractions.&#x20;

{% hint style="info" %}
We do not require you to use high grammar in punishments, but make sure that sentences have a meaning, and that you are not using slang terms.

For example:

> Usage of banned weapon <i class="fa-check" style="color:green;">:check:</i>

> he gonna insult me <i class="fa-xmark-large" style="color:red;">:xmark-large:</i>

You can avoid to put punctation at the end of the sentence and other minor things like this, though you must make sure that you sentence looks well-written.
{% endhint %}

* Leave of Absence / LOA has a cooldown of <mark style="color:yellow;">2 weeks</mark>, only LS may bypass this LOA cooldown. You can’t go on LOA for longer than 2 weeks, or less than 3 days.&#x20;

{% hint style="warning" %}
Please note! If you go on LOA mid week and haven't done quota (for example if you went on LOA on Friday)  you will still be infracted! Please schedule your LOA on days no later than Wednesday to avoid this!&#x20;

<p align="center"><a href="https://melonly.xyz/my/loa" class="button primary" data-icon="up-right-from-square">Request a LOA here</a></p>
{% endhint %}

* <mark style="color:yellow;">Only SHRs</mark> and above are permitted to use API commands through Melonly.&#x20;

{% hint style="danger" %}
Using API commands while not being allowed to may result in a punishment even up to a termination!
{% endhint %}

{% hint style="info" %}
No more than 1 staff members should go on duty at the same time
{% endhint %}
