# Roleplay Voting (STS)

Roleplay Votes are our way to call STS, but we the addition that we let people decide which RP they prefer to play next in these.

Sometimes during Roleplay Votes rules are explained to the players as a normal STS, but at the end additional messages to host a vote are sent.\
We will uncover how to host one right here, below!

***

{% hint style="warning" %}
Roleplay Votes can only be, and should be, hosted each 2 hours (120 minutes)
{% endhint %}

Hosting a Roleplay Vote is really simple, follow the step-by-step instructions below in order to do so:

{% hint style="info" %}
You can click the appropriate button on each command to send in order to copy it!
{% endhint %}

{% stepper %}
{% step %}
**Send the following message 5 minutes prior to the start of the Roleplay Vote**

{% code overflow="wrap" %}
```
:h A roleplay vote will begin in 5 minutes. Please wrap up all of your ongoing roleplays. Mod calls may be delayed at this time.
```
{% endcode %}

In the meantime, start preparing the are in the parking of the Sheriff's Office, or wherever you think the Roleplay Vote should be hosted (example: The prison is also a good option), by placing cones, barriers and more.


{% endstep %}

{% step %}
**Send the following message 1 minute prior to the start of the Roleplay Vote**

{% code overflow="wrap" %}
```
:m A roleplay vote will be hosted in 1 minute. Please end now all of your roleplays.
```
{% endcode %}
{% endstep %}

{% step %}
**Once it's time to start the Roleplay vote, execute this commands as they are listed here:**

{% code overflow="wrap" %}
```
:unjail others RP Vote
```
{% endcode %}

{% code overflow="wrap" %}
```
:wanted others RP Vote
```
{% endcode %}

{% code overflow="wrap" %}
```
:load others RP Vote
```
{% endcode %}

{% code overflow="wrap" %}
```
:bring others RP Vote
```
{% endcode %}

_\[Wait 15-30 seconds]_

{% code overflow="wrap" %}
```
:bring other RP Vote
```
{% endcode %}
{% endstep %}

{% step %}
**Once everyone is at the location, send the following command:**

{% code overflow="wrap" %}
```
:m STS (Shoulder to Shoulder) against the fence now, or you will be kicked!
```
{% endcode %}
{% endstep %}

{% step %}
**Wait until everyone is staying quiet and has stopped moving (collaborate with your colleagues to help yourself in achieving this), and execute the following command:**

<details>

<summary>Chaos in the server? Send these rules to the players before hosting the vote!</summary>

Coming soon!

</details>

{% code overflow="wrap" %}
```
:m Hands up: President RP | Sit: Military RP | Stand: Normal RP | Lay: Border RP
```
{% endcode %}
{% endstep %}

{% step %}
**Wait 30 seconds and then count the votes. Once you've got the RP winner, announce it via this command, and execute the following commands:**

{% code overflow="wrap" %}
```
:m [Winner here] has won the vote! We will begin shortly.
```
{% endcode %}

{% code overflow="wrap" %}
```
:load all RP Vote
```
{% endcode %}

{% code overflow="wrap" %}
```
:unwanted all RP Vote
```
{% endcode %}
{% endstep %}

{% step %}
**Remember to update the session's information in the discord on-duty channels if needed**
{% endstep %}
{% endstepper %}

***

That was all! For any further questions please contact an high ranking staff member.
