# Elections

Elections are the way each President RP starts.

These works like real life elections, but as a shortened version that should last approximately 15 minutes at maximum, or, in any way, not more than 30 minutes.

***

Elections are hosted at the Police Department's meeting room, and requires all players off the server to participate (you don't need to check if everyone is actually participating or not). Players are not required to vote, but are highly advised to.

## How to host elections

{% hint style="info" %}
You can click on the appropriate button on commands boxes to instantly copy them and paste them in-game!
{% endhint %}

{% stepper %}
{% step %}
### Set up the area

Head to the Police Department, go to the meeting room, and set up the area with crowd fences or any other type of item.

You must prepare at least 3 boxes for 3 candidates, any other type of room decoration is at your choice. Do not block entrances for any reason.\
You can also set up the area outside prepared for the convo. Each item should be placed only to improve the game experience, not ruin it (e.g. place cones to ensure that cars can only place themselves in one line, place barriers to avoid external vehicles from disturbing the convoy, etc...).

{% hint style="info" %}
HR+ staff members should spawn the appropriate map layout for faster item-placing and more reliably road blocks for the convoy.
{% endhint %}

Lastly start a peace time of 500 seconds with the following command, to avoid any RDM and chaos in the area.

{% code overflow="wrap" %}
```
:pt 500
```
{% endcode %}

{% hint style="warning" %}
Repeat this peace timer until the convoy has reached its first destination
{% endhint %}
{% endstep %}

{% step %}
### Announce the elections and wait for players

Announce the elections up to 3 times with the following commands.

{% code overflow="wrap" %}
```
:m Presidential elections are being hosted in the police department meeting room!
```
{% endcode %}

_\[Wait approximately 1 minute]_

{% code overflow="wrap" %}
```
:h Presidential elections are being hosted in the police department meeting room!
```
{% endcode %}

_\[Wait approximately 1 minute]_

{% code overflow="wrap" %}
```
:h Presidential elections are being hosted in the police department meeting room!
```
{% endcode %}

{% hint style="danger" %}
The :m type command is only allowed once, or if, after 3 announcements, a low number of players has shown up to the elections.&#x20;

Execute the commands in the exact order they are placed.
{% endhint %}

After approximately 5 minutes and 3 announcements, at least 2 rows of the meeting room should be full of seated players. <mark style="color:$danger;">Make sure they are all seated!</mark>

<details>

<summary>What if less than 2 rows of players show up?</summary>

You are allowed to run the :m type announcement again.

If, after another 5 minutes and more :m announcements 2 rows of people are still not present, we advise you to stop the roleplay and host another one.

</details>
{% endstep %}

{% step %}
### Start the elections procedure

Announce the following message:

{% code overflow="wrap" %}
```
:h Thank you all for being at this election, I will be now choosing three candidates.
```
{% endcode %}

Pick 3 random players from the room, ask each of them if they want to be a candidate and allow the ones who say yes to stand in the boxes you prepared earlier.

Repeat this process until you've found 3 players that have said yes to being a candidate. One box should contain only one candidate.

Announce then the following message:

{% code overflow="wrap" %}
```
:h The candidates have been choosen. They will now be given one minute to pronounce their speeches.
```
{% endcode %}

Inform the candidates that their minute has started, and wait 1 minute of time.

{% hint style="info" %}
It is <mark style="color:red;">NOT</mark> 1 minute per candidate, but 1 minute for all candidates at the same time.
{% endhint %}

{% hint style="warning" %}
You should write down which candidate is in which box before a lot of players will start flowing and crouding the boxed! (You might not remember who was in each box!)
{% endhint %}

Then announce the following message:

{% code overflow="wrap" %}
```
:h Voting has started! Please stand in the box of the candidated you are voting for.
```
{% endcode %}

Wait for players to stop moving into or within the boxes and, if you want, make sure that everyone has voted (don't loose time on AFK players). Wait at least 1 minute of time.

Now, count the number of player in each boxes, and determine:

* The most voted candidate, which will become the **President**
* The second-most voted candidate, which will become the **Vice-President**

Announce the results with the following commands:

{% hint style="warning" %}
Don't forget to replace square brackets \[] with the content regarding what's specified inside of them!



You should **NOT** type, for example: The player \[botek000999] has been elected.... <i class="fa-xmark" style="color:red;">:xmark:</i>

You **should** type, for example: The player botek000999 has been elected..... <i class="fa-check" style="color:green;">:check:</i>



You are allowed to shorten long players' names only in this specific case.
{% endhint %}

{% code overflow="wrap" %}
```
:h The player [Player] has been elected as President.
```
{% endcode %}

_\[Wait for the previous announcement to go away]_

{% code overflow="wrap" %}
```
:h The player [Player] has been elected as Vice-President.
```
{% endcode %}

<i class="fa-exclamation" style="color:red;">:exclamation:</i>Now make the President (and the Vice-President if he wants) join the Police Team and     wear the President's uniform that they can find at the Police Department's wardrobe.
{% endstep %}

{% step %}
### Initiate the convoy forming procedure

In the meatime of the elections occuring, a convoy should have set up outside the Police Department.&#x20;

Announce the following message:

{% code overflow="wrap" %}
```
:h Please form a Presidential convoy outside the police department. Disrupting the convoy setup may result in punishments.
```
{% endcode %}

Allow for players to start forming a convoy, and make sure that the President (and Vice-President if he wants) are being present at the scene, ready to depart.

***

Continue the convoy's formation and starting procedure in the next page <a href="convoy.md" class="button secondary" data-icon="arrow-right-long">Convoy Page </a>
{% endstep %}
{% endstepper %}
