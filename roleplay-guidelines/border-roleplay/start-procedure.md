# Start Procedure

### How to start a Border RP

{% stepper %}
{% step %}
**Select a location from the previously listed allowed locations**
{% endstep %}

{% step %}
**Set up the border using workers from DOT or by loading in one of the layouts**

{% hint style="info" %}
Only HR+ members can load in layouts since they have admin commands, if there is no HR+ in game you should get DOT members to set up the border or ask a SHR+ to use API commands to load in the layout.
{% endhint %}
{% endstep %}

{% step %}
**Setup the checkpoints**

At each border's area you should setup 2 checkpoints, one for each way of the road.\
You should also consider making spaces for:

* A checkpoint for officers to preform ID checks;
* Another one for vehicle searches;
* A place for staff cars and service cars to be parked cleanly and out of the way;
{% endstep %}

{% step %}
**Announce the RP start**

Copy and paste the following command, which will send an M type of announcement to all players in the server, letting them know of the RP starting.

Make sure to replace the location in the square brackets with the actual location. \
You can use the "copy" button on the box of the messages to directly copy it and paste it in game.

{% code overflow="wrap" %}
```
:m The roleplay has been changed to border at [Location].
```
{% endcode %}

{% hint style="info" %}
You should remain limited to one M announcement per RP change, to avoid frequent UI messages showing to all players in the server. If players don't show up to the border's area, please use H type of announcements first, and use M announcements again only if, after several tries, no one is still showing up.
{% endhint %}
{% endstep %}

{% step %}
**Handle the RP**

As a staff members handling the border RP you are only required to make sure everyone is respecting the rules.

Typical RP procedure includes players who try to cross the border and get their vehicle and personal data inspected by the police staff present at the border.
{% endstep %}
{% endstepper %}

{% endhint %}
