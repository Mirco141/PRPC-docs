# Border Roleplay

Border Roleplay (often abbreviated as Border RP), is a type of Roleplay which involves roleplaying a border within two spaces, with controls on vehicles, peoples and goods passing between the two spaces, hence involving the participation of both LEO[^1]s and normal players.

{% hint style="info" %}
Border Roleplay is not our primary roleplay for our staff members to host, you only host this is if there is a lack of staff or a lack of people in game to host a presidential roleplay.&#x20;
{% endhint %}

***

### Role Information

There isn't really a need for an host or any other type of role, all staff members on-duty should help out by monitoring the border area, ensuring there is no rule breakers, making frequent announcements about the location of the border and, finally, taking mod calls that show up.&#x20;

***

### Allowed Locations

* Red Bridge (Postal 900)&#x20;
* RiverCity Tunnel (Towards the end, postal 225)
* High Rock Park Entrance (Postal 1201)

***

### Useful Announcements

{% hint style="info" %}
You can click the appropriate button on each command to send in order to copy it!
{% endhint %}

{% hint style="warning" %}
Don't forget to replace square brackets \[] with the content regarding what's specified inside of them!



You should **NOT** type, for example: _....changed to border at \[Red Bridge]_ <i class="fa-xmark" style="color:red;">:xmark:</i>

You **should** type, for example: _.....changed to border at Red Bridge_ <i class="fa-check" style="color:green;">:check:</i>
{% endhint %}

To send when the RP is changed to border:

{% code overflow="wrap" %}
```
:m The roleplay has been changed to border at [Location].
```
{% endcode %}

{% hint style="warning" %}
If DOT is needed, add on to that message saying "DOT is needed to help setup the border."
{% endhint %}

To send every 1-5 minutes when the server's RP is border:

{% code overflow="wrap" %}
```
:h Welcome to PRPC, the current roleplay is Border and it is located at [location].
```
{% endcode %}

To send every 10 minutes approximately, or whenever there is chaos at the border's area:

{% code overflow="wrap" %}
```
:h Friendly reminder, random shooting or killing is not allowed at the border.
```
{% endcode %}

***

### Roleplay Rules

As a staff member guarding the border, you should make sure players are following the below reported rules. Normal server rules also apply.

* Civilians must stop at the check points and follow the police's instructions;
* All sirens are prohibited;
* Ramming is prohibited;
* RDM, or more generally, random shooting is not allowed at the border area.&#x20;

{% hint style="success" %}
It is allowed for civilians to start a motivated fight with the police at the border.
{% endhint %}

***
